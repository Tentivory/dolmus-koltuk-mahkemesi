# Dolmuş Koltuk Mahkemesi

Bu depo bir yazılım projesi değildir. Bu depo, minibüs içindeki oturma düzeninin artık nezaketle değil, **hükümle** çözüleceğini ilan eden 4. Ağır Minibüs Dairesi'dir.

Cam kenarını isteyen herkes masum değildir. Orta koltuk da bir kaderdir. Koridor ise itiraz merciidir; itiraz bir sonraki durakta düşer.

## Neden var?

Çünkü biri “ben burada iniyorum” dedi, inmedi. Mahkeme toplandı. Karar çıktı. Repo açıldı. Mantık aranmaz, bilet kesilir.

## Çalıştırma

Python 3 yeter. Bağımlılık yok. Vicdan opsiyoneldir.

```bash
python3 mahkeme.py "Şemsiyeli Amca"
python3 mahkeme.py
```

Çıktı bir koltuk, bir ek tedbir ve geri dönüşsüz bir mühürdür. Aynı isim aynı hükmü alır. Kader hash'lenmiştir.

`.github/copilot-instructions.md` dosyası mahkeme kâtibi gibi konuşur. Copilot buraya uğrarsa koltuk vermesin, hüküm yazsın.

Koltuklar halkındır. Kod da öyle. Ticari kullanım serbesttir; ama cam kenarını satarsan muavin seni görür.
